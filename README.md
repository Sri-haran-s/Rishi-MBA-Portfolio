PREVIEW LOCALLY
1. Extract this ZIP.
2. Open index.html in Chrome or another browser.
3. Use the navigation menu to visit the nine pages.

1. Replace the RV initials circle on Home with your own profile photograph.
2. Add the official semester-wise course lists to mba-journey.html. The programme structure was not among the uploaded files.
3. Add genuine classroom activity descriptions and photographs. These were not supplied, so no activities have been claimed.
4. Watch the five recommended talks and replace the takeaway prompts with your own one-line takeaways.
5. Add three to five personal learnings for each module covered so far, with genuine examples; update power words to match class content.
6. Add your LinkedIn link if available.
7. Verify the assignment files and all navigation after hosting.

GOOGLE SITES
This is a static HTML website package and cannot be imported into Google Sites in one click. To build it in Google Sites:
1. Open https://sites.google.com/ and create a blank site.
2. Create the nine pages using the page names shown in the navigation.
3. Copy the text from the corresponding HTML pages into Google Sites.
4. Upload the two assignment files to Google Drive and link them from the Business Communication page.
5. Add your profile photograph and genuine classroom photographs.
6. Click Publish, configure viewing access, and test the public link in an incognito window.
7. Submit the website URL on Google Classroom.

ALTERNATIVE HOSTING
You can host this package on a static website host that supports HTML/CSS. Upload the extracted folder contents and keep the assets folder in place so assignment links continue to work.

PRIVACY
Only the email address provided by the student is displayed. No phone number, home address, date of birth or government ID is included.
